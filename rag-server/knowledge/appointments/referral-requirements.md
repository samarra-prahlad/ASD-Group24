# Referral Requirements

## Current system behavior

This booking system does not currently check or enforce GP referrals for any
specialty. A patient can book directly with any specialty — including
specialists such as Cardiology, Neurology, or Orthopedics — without needing
a referral on file.

## Note for the team

Whether referrals should be required for certain specialties is a policy
decision that hasn't been made yet for this system. If a referral requirement
is added in future, it would need to be built into the booking flow itself
(e.g. checking for a referral record before allowing a booking with a
specialist), not just documented here.

Until that decision is made, this file reflects the system as it actually
works: no referral is required to book any appointment.
