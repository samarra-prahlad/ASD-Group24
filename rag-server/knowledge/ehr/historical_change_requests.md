# Historical Change Request Examples

## Example: allergy correction, approved workflow
An Update Allergies request with details "Add newly diagnosed shellfish allergy" was submitted and left pending review, showing the typical first step: the allergy addition is recorded but not yet reflected in the record until an admin approves it.

## Example: treatment correction, approved
An Update Treatment request with details "Fix misspelled medication name" was reviewed and moved to approved, showing that simple factual corrections to a treatment field are typically approved once verified against the original prescription.

## Example: diagnosis correction, rejected
An Update Diagnosis request with details "Diagnosis date recorded incorrectly" was reviewed and moved to rejected, illustrating that a request is rejected when the reviewer cannot confirm the claimed error against existing records.

## Example: administrative change, Other type
A request with request_type Other and details "Patient moved, update address" remained pending, showing that non-clinical administrative changes are also routed through the same change request process rather than a separate system.

## Example: notes correction flagged for review
An Update Notes request with details "Duplicate record flagged for review" stayed pending, showing that change requests are also used to flag data quality issues, not only to request a specific correction.
